# 在公司模板上出稿

很多公司有自己的 PPT 模板，母版上放着 logo、色条和页脚，主题里定好了颜色和字体。用户给了模板，就在模板上出稿，不再按参考图另起一套风格。

## 做了什么

- **母版原样保留**。成品就是在模板文件上加页，母版和所有版式都在，背景、logo、色条、页脚文字每一页都显示，和用户自己用模板新建一页一样。模板里自带的示例页会去掉。
- **颜色和字体来自模板**。主题里的标题字体、正文字体（含中文字体）直接用。主色优先取母版上真正画出来的颜色（顶部色条、色块、彩色封面背景），其次才是主题色，因为很多模板的主题色还是 PowerPoint 默认的蓝橙，从来没改过。
- **内容只排在可用区域**。母版和版式上的图形（logo、色条、页脚、侧边色带）占掉的地方不放内容。上边和下边的图形把内容往中间推，左右窄条把内容往里推。整份稿子按页面种类统一摆放，每页标题位置一致：本来就放得下就原样放，放不下就等比缩小、挪进可用区域。
- **四类页面各用一个版式**。封面用模板的标题版式，章节页用节标题版式，内容页用空白版式，结尾页用名字里带"结束、谢谢、封底、End"的版式，没有就和封面共用。某个版式的背景和内容页不一样（红色封面、深色结尾页），这一页会换一套跟它的底色配的颜色。
- **我们自己的页眉不画**。模板的母版就是页眉，系列名之类的居中页眉不再加；页脚来自原稿的仍然照抄。

## 文件

| 文件 | 内容 |
|---|---|
| `$W/template/template.pptx` | 去掉示例页的模板，出稿就在它上面加页 |
| `$W/template.json` | 读出来的结果，可以手改后 `apply` |
| `$W/template/template_card.png` | 确认卡：四类页面用的版式和可用区域（红框）、主色、强调色、字体、提醒 |
| `$W/template/layout_N.png` | 每个用到的版式渲染出来的样子（需要 LibreOffice），近似预览拿它当背景 |

## template.json 能改的字段

| 字段 | 说明 |
|---|---|
| `primary` | 主色，标题装饰、柱子、编号用它 |
| `accent` | 强调色，一页里最关键的一两个点用它 |
| `use` | `{"cover", "section", "content", "closing"}` 各用第几个版式（版式序号，字符串），`null` 表示没有，结尾页没有时和封面共用 |
| `layouts.N.free` | 第 N 个版式的可用区域 `[x0, y0, x1, y1]`，单位英寸，原点在左上角 |
| `layouts.N.bg` | 第 N 个版式的底色。背景是图片又没装 LibreOffice 时会先按白色处理，要手动改 |

改完运行 `python3 $S/template_kit.py apply $W`，重新生成 `style.json` 和确认卡。

## 要提醒用户的情况

- **主题色是 PowerPoint 默认的蓝橙，母版上也没有彩色图形**：主色多半不是公司色，问用户公司色是什么，改 `primary`。
- **模板不是 16:9**（比如 4:3）：内容按比例缩小放进去，上下会留白。能找到 16:9 版本的模板更好。
- **版式中间有图形**（水印、大面积底纹）：内容会压在上面，确认卡里看一眼，必要时手改 `free`。
- **模板字体电脑上没装**：QA 会提醒，告诉用户装上字体，或者发给别人前在 PowerPoint 里嵌入字体。
- **只给了模板截图、没有文件**：截图不是模板，当参考图走美化路线；有 VI 手册就走品牌套件。

## 不做的

- 不往模板自己的标题、正文占位符里填字。标题和正文由萝卜 PPT 的版式排，位置和字号跟着版式走，可能和模板占位符的位置不完全一样。
- 不改模板的母版和版式。
- 全出血的大图版式（整页铺满的插画）在模板上会被框在可用区域里，不再顶到页边。
